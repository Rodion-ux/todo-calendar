# Календарь задач

Тестовое задание: простой сайт «Список задач», сделан с помощью Claude Code

Демо: https://todo-calendar-6f1.pages.dev

## Что умеет

- Создать задачу: кнопка «Новая задача» или клик по пустому месту в сетке, время подставится само
- Отметить выполненной: кружок на карточке
- Удалить: корзина на карточке или кнопка в окне задачи, после удаления 4 секунды можно нажать «Вернуть»
- Задачи хранятся в localStorage и остаются после перезагрузки страницы

Дополнительно: виды «Месяц», «Неделя» и «День», перетаскивание задач на другое время и день, описание задачи, поиск с подсказками, фильтры по категориям и статусу, мини-календарь, версия для телефона

## Как запустить

Сборки нет. Откройте `site/index.html` в браузере или раздайте папку `site` любым статическим сервером

Один HTML-файл: HTML, CSS и JavaScript без библиотек, шрифт Manrope лежит в `site/assets`
